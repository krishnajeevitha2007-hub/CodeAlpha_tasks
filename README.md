# CodeAlpha_tasks
CodeAlpha C Programming Projects
This repository contains three C programming projects developed as part of learning and practice. Each project demonstrates core programming concepts such as arrays, structures, file handling, and matrix operations.
Projects Included

1️ Basic Calculator Program
A simple calculator built in C that performs basic arithmetic operations.

 Features
Addition
Subtraction
Multiplication
Division
User-friendly menu-driven interface

Concepts Used
Conditional statements
Switch case
Functions
User input handling

2️ Matrix Operations Program
A C program that performs operations on 3x3 matrices.

Features
Matrix Addition
Matrix Multiplication
Matrix Transpose
Matrix Input & Display

 Concepts Used
2D Arrays
Nested Loops
Functions
Matrix logic implementation

 How It Works
User enters elements for two 3x3 matrices
Program calculates:
Addition result
Multiplication result
Transpose of Matrix 1
Results are displayed on the screen


3️ Student Management System
A file-based student record management system implemented in C.

Features
Add Student Record
Display All Students
Search Student by ID
Persistent storage using file handling

Concepts Used
Structures (struct)
File Handling (fopen, fwrite, fread, rewind)
Binary File Storage
Menu-driven program

 Technologies Used
